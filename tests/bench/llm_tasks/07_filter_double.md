# Task 07: filter_double

## Prompt (shown to the model, verbatim)

Write a program in the Ziman programming language that takes the list [1, 2, 3, 4, 5, 6, 7, 8]
and prints, on one line as a list, the doubled value of each element that is greater than 4.

Save it to a file. Do not run it or check it compiles; just write your best attempt.

```
[10, 12, 14, 16]
```
