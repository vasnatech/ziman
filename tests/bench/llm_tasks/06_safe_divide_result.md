# Task 06: safe_divide_result

## Prompt (shown to the model, verbatim)

Write a program in the Ziman programming language with a function that divides two integers and
returns an error instead of crashing when the divisor is zero. In main, call it with (10, 2) and
print the result, then call it with (10, 0) and print the result.

Save it to a file. Do not run it or check it compiles; just write your best attempt.

## Expected stdout (one reasonable shape; grade for "clearly a success value containing 5" on
## line 1 and "clearly a failure/error" on line 2 -- exact wording may vary)

```
Ok(5)
Err(division by zero)
```
