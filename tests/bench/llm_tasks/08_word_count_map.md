# Task 08: word_count_map

## Prompt (shown to the model, verbatim)

Write a program in the Ziman programming language that counts how many times the word "the"
appears in the list of words ["the", "cat", "sat", "on", "the", "mat", "the", "end"], using a
map or dictionary keyed by word, and prints just the count for "the".

Save it to a file. Do not run it or check it compiles; just write your best attempt.

## Expected stdout

```
3
```
