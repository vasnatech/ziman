# Task 05: enum_shape_area

## Prompt (shown to the model, verbatim)

Write a program in the Ziman programming language that defines a Shape type that can be either a
Circle with a float radius or a Rectangle with float width and height, a function that computes
its area (use 3.14159 for pi), and a main function that prints the area of a Circle with radius
2.0 and the area of a Rectangle with width 3.0 and height 4.0, each on its own line.

Save it to a file. Do not run it or check it compiles; just write your best attempt.

## Expected stdout

```
12.56636
12.0
```
