# Task 10: json_roundtrip

## Prompt (shown to the model, verbatim)

Write a program in the Ziman programming language that defines a Person type with a name
(string) and age (integer), serializes a Person named "Ada" aged 36 to a JSON string and prints
it, then parses that JSON string back into a Person and prints just the age.

Save it to a file. Do not run it or check it compiles; just write your best attempt.

## Expected stdout (field order in the JSON object may vary)

```
{"name":"Ada","age":36}
36
```
