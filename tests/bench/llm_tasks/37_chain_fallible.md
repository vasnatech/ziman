# Task 37: chain_fallible

## Prompt (shown to the model, verbatim)

Write a program in the Ziman programming language with two steps that can each fail: one turns text into a number, the other halves it but fails on an odd number. Run them in sequence on "8" and then on "7", printing the outcome of each on its own line.

Save it to a file. Do not run it or check it compiles; just write your best attempt.

## Expected stdout (line 2 may be any clear failure indication)

```
4
not even
```
