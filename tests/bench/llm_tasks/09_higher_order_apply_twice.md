# Task 09: higher_order_apply_twice

## Prompt (shown to the model, verbatim)

Write a program in the Ziman programming language with a function `apply_twice` that takes a
function and a value, and applies the function to the value twice (e.g. apply_twice(f, x) is
f(f(x))). In main, define a function that doubles an integer, use apply_twice to apply it to 3,
and print the result.

Save it to a file. Do not run it or check it compiles; just write your best attempt.

## Expected stdout

```
12
```
