# Task 24: group_by_first_letter

## Prompt (shown to the model, verbatim)

Write a program in the Ziman programming language that groups the words ["apple", "avocado", "banana", "blueberry", "cherry"] by their first letter and prints one line per letter, in alphabetical order, in the form letter:count.

Save it to a file. Do not run it or check it compiles; just write your best attempt.

## Expected stdout

```
a:2
b:2
c:1
```
