- [x] **E5** Rate limiting and lockout on login, an MFA attempt cap, a TOTP replay guard, and encryption of TOTP secrets at rest. (D item 12, S3, S4; M) Done: two `ziman` (this repo) additions the backend needed rather than worked around, both in `crypto`/`otp` (native, `lib/core`, so any consumer gets them) -- `crypto.aes_gcm_encrypt`/`aes_gcm_decrypt` (a fresh 12-byte nonce, `nonce || ciphertext || 16-byte tag`, `Err` only for a wrong key length) and `otp.totp_matching_step` (the 30-second step a code matched, so a caller can refuse a repeat of one already spent; `totp_valid` is now defined in terms of it).
